# Estructura de Respuesta Final

Cuando se analice un chat de cliente, entregar:

## Diagnostico breve

- Canal.
- Etapa del cliente.
- Intencion real.
- Objecion principal.
- Riesgo fiscal o contable.
- Nivel de firmeza recomendado.

## Respuesta recomendada

La mejor version para enviar.

## Version mas directa

Mas firme, sin ser seca.

## Version mas suave

Mas cuidadosa, util si el cliente esta frio o sensible.

## Que no decir

Advertencia concreta sobre una respuesta que podria dañar la venta o crear riesgo fiscal.

## Pregunta de avance

Una pregunta clara que lleve a diagnostico.

## Evaluacion con rubrica

Calificar de 1 a 10. Si queda por debajo de 8, reescribir antes de entregar.
